# 文件浏览

开发候选实现列表、图标与列三种原生呈现；新增列视图的实际窗口仍待验收。本地与远程窗格独立，每个标签保留自己的视图模式；新标签默认列表，退出后不恢复模式。可调图标大小、文件缩略图及完整浏览状态持久化尚未实现。

窗格标题旁的系统分段控件切换视图；Command-1 / Command-2 / Command-3 对应当前焦点窗格的图标／列表／列视图。文件 ID 维持同一选择，切换后恢复键盘焦点，Space 快速查看，Return 打开当前选择。图标支持 AppKit 键盘多选；双击打开实际点击的文件，空白双击不打开已有选择。排序菜单按名称、大小或修改时间升降序排列，筛选和隐藏文件设置沿用列表行为。

三种视图共享右键菜单：打开或下载、文本编辑、快速查看、文件信息、上传、重命名和删除。操作沿用既有工作流、冲突确认和安全传输，视图不单独实现网络请求。工具栏与文件菜单直接观察当前 Workspace 的选择和加载状态，加载／认证期间禁用传输；执行入口也检查状态。

多选菜单新增批量重命名，共用文件菜单与 Command-Shift-R，沿用同一预览／排除／结果表单，见 `batch-rename.md`。FTP 系列的远程浏览也读取包含隐藏项目的完整元数据，使隐藏项目切换及未完成改名的暂存结果使用一致的目录快照。

## 列视图

列视图使用并排的可复用 NSTableView，与列表共用 `FileNameCell`、28 pt 行高、名称中间截断、文件符号和系统语义色。每列宽 260 pt，横向滚动到新目录；标题保留完整路径提示与双语辅助功能名称。单选文件夹进入下一列；文件保持选择，Return／双击打开，Space 快速查看。左箭头回到已访问的上一列，右箭头打开所选目录；右键选择目录不会先进入目录。多选仍沿用现有传输和文件菜单。

切换到列视图以当前目录为浏览根，不额外读取完整绝对祖先路径。新目录仍由已有 LocalFiles／RemoteClient／S3Client 在后台读取；选择已访问列使用已有元数据快照，刷新重新读取当前目录并丢弃旧子列。直接跳转到其他路径、切换标签／连接或离开列模式会开始新的列历史；不复用其他连接的条目。所有列共用筛选和排序；本地加载完整元数据快照，隐藏文件切换不额外执行目录 IO。筛选准备可取消，旧版本不得发布。

历史最多保留 24 列；祖先合计最多 50,000 条和约 16 MiB 估算元数据，超限从左侧移除祖先。当前列始终完整，不静默截断文件；这些是缓存边界，不是进程 RSS 上限。S3 列与分支识别使用原始 UTF-8 字节，保留空桶根、重复斜线及 Unicode 形式，不按 POSIX 路径规范化。

列滚动区接收投放到该列目录的文件 URL；接受时先激活该列快照，再固定目标连接、路径和同名条目。空状态标签不截获输入。未实现悬停进入文件夹、按文件夹行投放或远程文件承诺。

新增五项核心用例覆盖分支刷新、路径跳转、S3 原始字节、深度和元数据边界；另有真实文件服务器／HTTPS S3 层级用例。协议测试证明目录数据适配，不能证明鼠标、键盘、拖放、英文宽度或过渡帧率。当前界面控制通道仍关闭，列视图和整包四组合均保持待验收。

图标采用 [NSCollectionView](https://developer.apple.com/documentation/appkit/nscollectionview) 和 [NSCollectionViewFlowLayout](https://developer.apple.com/documentation/appkit/nscollectionviewflowlayout)，复用 AppKit 单元格。后台筛选/排序完成后才替换数据版本，不将每个文件放入 SwiftUI 布局或玻璃动画。类型图标来自系统 UTType，不读取文件内容、不下载远程缩略图；类型图片使用 countLimit 为 128 的 NSCache，属于缓存回收策略，不能视作整个进程内存上限。名称显示最多两行，完整名称保留于提示与辅助功能标签。

玻璃仍集中于系统工具栏、标签和操作控件，文件区域使用清晰的原生内容呈现。依据 [Apple Liquid Glass adoption](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)。

## 文件 URL 拖放

列表、图标和列的滚动区共用 AppKit 文件 URL 接收入口。本地源只提供复制，远程栏接收去重的文件 URL；未连接、连接中、远程载入中或文件区禁用时拒绝。空目录提示不拦截输入，接受时用系统强调色描边。上传在后台读取本地元数据前固定目标连接、路径和同名文件快照，再进入已有队列、递归与冲突工作流；列表／图标目标是当前目录，列视图目标是接收列的目录，尚无悬停进入文件夹或按文件夹行投放的行为。

2026-10-08 增补验收：

- 诊断构建中，列表单文件及图标多选文件/目录拖入远程栏产生真实 SFTP 任务。原生拖动后继续一次目标点击，才完成自动化输入中的投放；接收回调分别得到 1 / 2 个 URL。三个叶文件 SHA-256 与本地源一致，递归任务处理 2 / 2 项，源文件保留。
- 移除全部鼠标/拖放诊断日志并重建后，实际窗口核对指纹、上传到空目录、保留两份与冲突取消通过。图标多选中文文件和目录通过工具栏完成递归上传，目标哈希一致。取消不增加任务，最终四项完成。
- 最终构建的坐标输入控制器返回 `noWindowsAvailable`；应用绑定刷新、控制运行环境重置、窗口置前及系统尺寸还原均未恢复拖动。语义辅助功能操作和真实传输可用，但不能代替原生投放验证。因此空目录拖放和最终候选拖放保持待验收。
