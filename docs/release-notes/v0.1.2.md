AetherTransfer 0.1.2：全新蓝色双向流图标，完善独立安装包。
AetherTransfer 0.1.2 introduces a new blue bidirectional-flow icon and improves standalone packaging.

- 应用与官网使用同一份新图标，覆盖 Retina 和小尺寸图标。/ The app and website share the new icon, including Retina and small sizes.
- FTPS 使用随应用附带的证书根，避免依赖开发机的 Homebrew 证书路径；证书验证保持开启。/ FTPS uses bundled certificate roots instead of the developer machine's Homebrew path; certificate verification remains enabled.
- 安装包附带实际动态依赖的许可证及源码构建配方；打包时拒绝覆盖正在运行的输出应用。/ Includes licenses and source build formulas for embedded libraries; packaging refuses to overwrite a running output app.

Apple 芯片 · macOS 26.0+ / Apple silicon · macOS 26.0+
支持 FTP、FTPS、SFTP；WebDAV、S3 / R2 尚未包含。/ Supports FTP, FTPS and SFTP; WebDAV and S3 / R2 are not included.
