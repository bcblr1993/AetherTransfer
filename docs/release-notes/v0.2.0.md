AetherTransfer 0.2.0：Transmit 5 深度对齐——全协议扩展、级联分栏与画廊视图、Servers Launchpad、三标签检查器、规则与脱敏日志、Droplets 与加密书签同步。
AetherTransfer 0.2.0 brings Transmit 5 parity across 10 protocol modes, cascading Miller columns and gallery view, Servers Launchpad, 3-tab inspector, rules and redacted transcripts, Finder Droplets, and encrypted vault sync.

## 主要更新 / Highlights
- **全协议扩展 / Protocol Expansion**：新增显式 FTPS (`AUTH TLS`)、WebDAV / WebDAV HTTPS、Amazon S3 / Cloudflare R2 / MinIO（原生 SigV4、分段上传、元数据与 Presigned URL）、Backblaze B2、Azure Blob 与 OpenStack Swift，全面覆盖 10 种协议模式。
- **浏览器与启动台 / Browser & Launchpad**：新增级联 Miller 分栏、画廊分屏预览、缩略图网格、聚焦模式与本地⇄本地 / 服务器⇄服务器双栏切换；新增 Servers Launchpad（颜色标签、文件夹关联）与自定义常用位置。
- **三标签检查器 / 3-Tab Inspector**：支持文件夹大小计算、分块 SHA-256 / MD5 校验、递归 POSIX 权限修改，以及云存储对象元数据编辑与临时签名链接生成。
- **规则、日志与自动化 / Rules, Transcript & Automation**：新增 Skip Rules 谓词规则与 ASCII 扩展名编辑器；传输队列支持置顶、一键重试与脱敏协议日志；支持导出 Finder Droplets、`aethertransfer://` URL Scheme、菜单栏闪电微件、SSH 密钥管理器、外部编辑器保存回传与 `.aethersync` 零知识加密保险箱。

## 系统要求与范围 / Requirements & Scope
Apple 芯片 · macOS 26.0+ / Apple silicon · macOS 26.0+
需第三方 OAuth 应用凭据的消费级云盘（Box、Dropbox、Google Drive、OneDrive）暂未包含。/ Consumer OAuth cloud drives (Box, Dropbox, Google Drive, OneDrive) require third-party OAuth app credentials and are not included.

SHA-256 见 `SHA256SUMS.txt`。/ See `SHA256SUMS.txt` for checksums.
