# 批量重命名

开发候选为本地及 FTP、显式／隐式 FTPS、SFTP、WebDAV／HTTPS 提供同一套中英文批量重命名表单。S3 对象复制／改名仍待实现，不启用这个入口。文件菜单的“批量重命名…”或 Command-Shift-R 使用当前焦点窗格的选择；多选右键菜单沿用相同入口。

## 预览与规则

- 替换文字：区分大小写的字面匹配，可用空替换删除文字，不执行正则表达式或命令。
- 添加文字：分别填写前缀、后缀。
- 名称与编号：基本名称、分隔符、起始编号、正的编号间隔及最少位数；编号不因语言或排除项目而改变。
- 默认保留文件的最后一段扩展名；可明确选择处理完整文件名。`.env` 的首个点不是扩展名，文件夹名称始终完整处理。

后台读取同一目录的实际所选项目与完整兄弟名称，再按原名称 UTF-8 字节顺序生成预览。输入有 180 ms 合并窗口，纯名称计算在可取消 worker 中完成；更新时保留上一份原生表格并禁用执行，避免逐键重建表格。名称原文不翻译，规则、列标题、状态与错误按当前语言显示。

初次打开及规则未填写完整时显示实际原名称、待填写状态与中英文指引，禁用执行，不把正常空白草稿标为操作失败。编号指引区分起始值、间隔和最少位数；有效后才生成新名称。提示、进度和实际错误复用固定反馈区，长错误可滚动查看，原有排除选择保留。

原名称、新名称和状态逐项显示，可排除项目。检查空名称、点路径、斜线、换行／NUL、255 字节上限、重复名称及未移动项目占用。冲突判断保守折叠大小写与 Unicode 规范形式，实际路径／命令保留原始字节；因此某些大小写敏感服务器允许的同目录变体仍可能被阻止。有效预览才启用“重命名所选项目”，不会覆盖冲突项或静默截断范围。

最多选择 1,000 项、读取 10,000 个兄弟项目及约 1 MiB 名称字节。目录枚举和本地属性读取离开主线程；FIFO／设备文件拒绝，符号链接改名只作用于链接本身，不修改链接目标。只改所选目录条目的名称，不递归改子项。

## 执行与停止

执行前核对端点、目录名称集合及所有待改项目的元数据；每步再核对名称集合与当前源。新建项目、移除／替换源、大小／修改时间／类型或权限变化都会停止，不能沿用旧预览继续写入。

先处理不会占用现存源名称的项目。名称交换、编号循环与仅修改大小写的改名，使用同目录唯一 `.aethertransfer-rename-UUID` 名称打破依赖；这些暂存项目仍是原始文件／目录，不是复制品。每一步核对后才计为完成。

本地固定目录描述符、核对设备／inode，通过 `renameatx_np(..., RENAME_EXCL)` 排他改名，并使用不跟随最终链接的属性核对。该调用不交换或删除目标，已完成条目保持原始内容、权限和 inode。描述符防止路径在核对之后被重定向到另一个目录；文件源检查和调用之间仍不能锁住其他进程对源条目的替换。

WebDAV 使用 `MOVE` 与 `Overwrite: F`。FTP／SFTP 在命令前重新读取包括隐藏项的目标目录并拒绝已存在名称，但它们通过当前 curl 后端无法保证“检查与改名”之间的原子无覆盖，表单明确提醒避免其他客户端并发修改。远程版本来自目录元数据，不能证明修改时间与大小都不变的内容更新；完整服务器并发矩阵仍待扩展。

停止／失败不会回滚已核对的改名，也不自动删除或覆盖任何暂存项目。结果保留已核对的当前名称；网络命令可能在取消前已被接受时，列出源／目标两个可能名称，不报告成功。未完成循环可能留下原内容的暂存名称，结果中明确显示。“查看结果”回到固定目录，并在需要时显示隐藏项目，让用户核对后继续处理。结果尚未跨重启持久化，关闭前应核对这些名称；自动恢复与撤销继续待办。

## 验证与界面边界

10 项新增核心用例覆盖规则／扩展名、字节与模式保持、编号循环、大小写／链接、排除与冲突、旧源／新目标／父目录替换、部分停止与暂存结果、执行中目标出现、特殊文件和目录上限。真实六种文件服务器往返、隐藏冲突、旧源与编号循环及受控 SFTP 取消由 4 项新增真实协议用例验证；状态以本轮日志及同提交 CI 为准。

表单复用 `SheetHeader`、`FormFieldRow`、`SupportingText`、`InterfaceMessage`、`SheetActions`；900 × 640 pt 的窗口保留可滚动规则区、原生 28 pt 复用表格及固定操作区。不为输入、行变化或进度增加自定义动画，只有一个主要玻璃按钮。中文／英文、浅／深色、输入法、Tab／Enter／Escape 和实际窗口尺寸仍待当前候选实机验收；协议通过不能证明视觉或动效通过。
