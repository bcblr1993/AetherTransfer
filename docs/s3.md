# S3 连接与文件传输（开发中）

开发候选提供原生 S3 连接表单、桶范围的前缀浏览、文件与递归目录上传下载、快速查看和 UTF-8 文本编辑，沿用共享队列、列表/图标、多标签、冲突选择和文件信息。仍在验收中；同步和重启恢复尚未接入 S3。现有 FTP/SFTP/WebDAV 用户工作流继续使用原来的协议客户端。

## 已实现的边界

- 文本编辑复用现有原生／外部编辑器与 5 MiB 限制；读取核对版本和内容，保存绑定原 ETag 条件，不自动覆盖已变化对象或重建被删除的对象。取消或冲突保留用户草稿，multipart abort 失败复用已有非秘密清理记录。真实隔离服务门禁与 GUI 验收分别记录，详见 [编辑流程](editing.md)。

- 路径式端点、区域、Access Key / Secret Key；可携带已有 Session Token，尚未获取或刷新 IAM Role 凭据。端点资料与分片清理记录为非秘密 Codable 数据，凭据单独传入，不在 URL 中携带。
- CryptoKit SHA-256 / HMAC 实现 SigV4；签名包含 Host、所有传入条件头、Content-MD5 与 x-amz 字段。libcurl 保留原始路径且不尝试 Basic/Digest、不跟随重定向；严格 TLS 验证，明文仅允许 loopback 测试。
- ListObjectsV2 以 `/` 分隔前缀，按 S3 URL/query 规则解码对象、前缀与分隔符（`+` 是空格，`%2B` 是加号），逐页原样传递不透明 continuation token。对象键按 UTF-8 字节识别，不归一化 `.`、`..`、重复斜杠、Unicode NFC/NFD；对象与同名前缀分别识别。空路径分量显示 `/`。当前文件夹的标记不作为子文件展示。
- 单页 XML 最多 4 MiB / 32,000 节点 / 24 层，拒绝实体、异常命名空间、重复字段、重复对象与不完整分页。全目录最多 100,000 项 / 32 MiB 估算元数据；超限提示浏览更具体的前缀。
- HEAD/ETag 版本核对、If-Match GET 与 Range 内容摘要。下载先核对远程 SHA-256，再写自己创建的 0700 暂存目录；完成校验后使用现有原子提交，不默认覆盖本地文件。
- 非空文件上传使用 multipart（最低 8 MiB 分片、自适应至最多 10,000 片，源文件最多 5 TiB），每片从原文件精确切片，256 KiB 缓冲预读计算 SHA-256 与 Content-MD5，不创建整份上传副本。源文件身份/大小/时间戳在预读前后及最终提交前核对。
- 空文件使用带摘要的条件 PUT；新对象 If-None-Match `*`，明确覆盖已有对象使用原 ETag 的 If-Match。非空上传只在条件 CompleteMultipartUpload 成功、XML 根/桶/键/ETag 合法后返回成功；HTTP 200 的 Error XML 也会拒绝。
- 原生传输支持当前会话暂停/继续、限速和取消；取消/失败独立 abort 自己的 upload ID。abort 失败返回非秘密 `S3MultipartCleanup` 记录，可用重新认证的同桶客户端重试。应用会持久保存失败的 abort 记录；在“保留的传输”中连接同一端点/桶后可重新认证并重试清理。它不代表重启续传，崩溃前未登记的 upload ID 也不包含在该列表中。

## 原生连接与操作

协议选择 S3，服务器地址只填主机名，默认 HTTPS 443；填写存储桶和区域，起始前缀为空表示桶根目录，非空前缀以 `/` 结束。R2 的区域是 `auto`，但真实 R2 条件上传兼容性仍待独立验收。Access Key、Secret Key、已有 Session Token 可由用户勾选存入 Keychain，收藏只保存非秘密字段。

可选自定义 CA 文件仍严格验证证书与服务器名称；未选择时使用应用自带的公共根证书。导入收藏会清除自定义 CA、主机信任和私钥路径，并分配新的凭据标识，不能自动读取本机已有钥匙串资料。收藏更新会先把新凭据写入独立标识，再提交资料；失败时不改变旧连接的凭据绑定，待清理的旧标识会在再次保存时重试。

S3 前缀、对象与同名前缀的选择标识按字节区分，不经过文件路径归一化。编码标识在后台构建时缓存，界面选择和刷新不重新编码全部键。普通文件支持覆盖、跳过、保留两份；新建文件夹写入条件空标记，对象删除由明确确认触发。暂未适配的编辑、重命名、同步与前缀删除明确禁用或提示，不能误执行本地动作。S3 无单文件保留进度入口；失败后重试会重新传输。

## S3 快速查看

普通对象通过现有快捷键、文件菜单或文件信息中的“快速查看”入口打开，沿用原生 Quick Look 窗口、中英文标题、读取进度、取消／重新读取与窗口关闭清理。前缀不能预览。先 HEAD 核对大小与 ETag，超过 128 MiB 时在创建缓存之前拒绝；随后使用现有条件 GET、SHA-256 核对和原子本地提交形成快照，最后再次 HEAD 核对版本。取消、版本变化和失败不能发布快照，清理不继承读取任务的取消状态。

快照位于专用 0700 缓存租约的 payload 子目录中，`.lease` 对象不会覆盖归属记录。服务端对象键始终按原始字节传输；点名称和超过本地文件名长度的对象使用安全的私有快照名，尽量保留短的字母／数字扩展名，窗口仍显示原始名称。关闭后只清理自己的租约，不写入或删除远程对象。缓存沿用现有启动回收及活动锁保护；不额外持久保存凭据。

当前源代码包含 2 项核心回归和 4 项真实 HTTPS 回归：中文／特殊字符、保留名称与空对象、缓存权限／活动锁／幂等关闭、超限与缺失对象、取消清理、同大小源变化拒绝。核心回归及 arm64 release 编译已通过；本次同提交协议、应用打包与原生窗口操作仍需独立核对。界面控制辅助服务未恢复，运行中的旧开发包尚未替换，不能把编译或协议测试当作新预览窗口的实际 GUI 通过。

## 递归目录传输

本地目录上传映射为原始前缀下的对象，每个目录写入零字节标记以保留空目录；包含隐藏文件与空文件。先在后台扫描完整本地清单、拒绝符号链接与特殊文件、验证全部目标键的 1,024 字节限制，再开始写入。前缀下载逐层分页扫描，记录对象大小与 ETag；每个文件传输前重新核对版本，提交前继续验证 SHA-256。扫描、传输和校验共用一个队列槽，可暂停或取消。

目录冲突支持拒绝、跳过整个目录、保留两份以及明确的合并覆盖；合并保留无关目标文件，不执行镜像删除。保留两份的目录使用 `名称 (2)` 等候选名，重新核对目标并以排他创建或条件对象提交防止静默覆盖。整体进度包含总字节、处理项目数与跳过数。

递归下载先验证整棵树的本地映射，拒绝 `.`、`..`、空路径分量、同名对象/前缀、大小写或 Unicode 归一化后可能重合的名称；即使目标卷区分大小写，也保守拒绝这类名称。不会把原始 S3 键归一化后写成另一个文件。包含内容的 trailing-slash 对象会报错，不能当作空目录丢弃内容。当前不提供此类目录的自动重命名映射。

目录不是事务：取消或失败会清理正在传输的临时文件 / 自己的 multipart 上传，已提交的叶文件和已创建的目录或标记保留。不会回滚用户文件，也不承诺外部进程同时修改目录时的原子快照。目录暂不保留重启进度或一键重试，应重新选择目录并决定冲突处理。清单沿用 32 MiB 估算元数据与 64 层限制，版本表随清单有界增长；超限需要分批选择子前缀。

## 仍待验收与限制

- 没有用 AWS/R2/DreamObjects 实际账户验收；隔离 MinIO 成功不代表这些服务全部兼容。R2 区域、端点及条件 multipart 行为必须在真实服务单独核对，不能通过降级无条件覆盖来绕过失败。
- 不包含桶发现/创建、虚拟主机式端点、服务商预设、IAM Role 获取/刷新、OAuth、复制/重命名、递归删除、版本选择、ACL 或 SSE/KMS。
- Multipart 尚无重启保留/恢复；当前取消会 abort，不承诺保留进度。网络响应丢失时可能无法确定最终提交状态，只报告失败/未确认成功，不回滚可能已经提交的目标。
- 若服务在 InitiateMultipartUpload 后未提供有效 upload ID，无法确定可安全清理的对象；不能猜测或批量删除其他上传。
- 原始键编码/Unicode 区分已有核心测试；MinIO 与 macOS 文件系统的特殊键、同名对象/前缀、Unicode 兼容限制仍需实际 AWS/R2 与应用浏览/落盘测试。
- 此版本 loopback MinIO 的根列表展示 `same` 对象时未同时展示 `same/` 前缀；独立签名请求得到同一结果。客户端不臆造服务未返回的前缀。同名对象/前缀的解析已有单元测试，真实云服务仍待验收。
- MinIO 拒绝含点路径分量 / 重复斜杠的键，并在 multipart 对象名检查中拒绝尾斜杠；相关客户端映射与非空标记保护由核心测试覆盖，真实服务落盘验收仍需 AWS/R2。该测试服务限制不能作为客户端支持任意 S3 键的完整证明，见 [固定版本的键验证源码](https://github.com/minio/minio/blob/7aac2a2c5b7c882e68c1ce017d8256be2feea27f/cmd/object-api-utils.go)。
- 尚未完成全部应用 GUI 矩阵、真实 abort 失败/重试故障注入、R2/WAN 性能、长期能耗与完整 Transmit 对齐验收；没有发布安装包或公开性能承诺。
