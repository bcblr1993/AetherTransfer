AetherTransfer 0.1.1：修复书签密码保存，并支持拖到任意位置上传下载。
AetherTransfer 0.1.1 fixes saving bookmark passwords and adds drag-and-drop to any location.

## 修复 / Fixes
- 新建书签默认把密码保存到钥匙串；钥匙串里没有密码时，连接前会请你输入并可选择保存。/ Bookmark passwords are saved to Keychain by default; if none is stored you are asked before connecting, with an option to save.

## 新功能 / New
- 把文件拖到列表或图标视图中的文件夹上，即上传或下载到该文件夹。/ Drop onto a folder in list or icon view to upload or download into it.
- 远程文件和文件夹可直接拖到访达、桌面或其他应用，下载走传输队列，校验后才交付。/ Drag remote files and folders into Finder, the Desktop or other apps; downloads run through the queue and only verified files are delivered.
- 列表视图支持多选拖动。/ Drag multiple selected rows in list view.

## 系统要求 / Requirements
Apple 芯片 · macOS 26.0+ / Apple silicon · macOS 26.0+
