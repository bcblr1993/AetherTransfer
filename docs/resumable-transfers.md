# 保留进度与断点续传

开发候选已接入单个普通文件的保留进度、进程重启后的恢复和明确丢弃。目录递归、同步任务和完整批量任务恢复尚未接入，不能据此宣称完整 Transmit 对齐完成。

## 使用

- 在活动列表选择「保留进度」，任务停止后显示「待续传」。选择「继续传输」会先核对源文件与已传内容。
- 退出时仍有活动任务，会要求先完成、保留或取消。保留后可退出；下次在文件菜单或活动栏打开「保留的传输」，连接原服务器后继续。
- FTP、SFTP、显式/隐式 FTPS 支持上传和下载按偏移继续；WebDAV HTTP/HTTPS 下载要求服务器正确支持 Range。
- 普通 WebDAV PUT 不支持按偏移上传；界面明确显示「从头上传」。必须点击该操作后才会删除此任务的远程暂存文件并重新上传。
- 「取消」或「丢弃进度」清理本任务的部分文件。离线时远程暂存可能无法删除，会保留「待清理」记录，连接后重试丢弃。原始文件与原有目标不由清理操作删除。

保留记录位于用户 Application Support 的 `AetherTransfer/Transfers`；下载部分文件在目标目录内的专属 UUID 目录，上传部分文件在远程目标目录内的专属 UUID 暂存文件。它们属于用户的待续传数据，不进入测试/构建清理名单；请在恢复列表明确丢弃不需要的进度，以释放空间。

## 内容与凭据边界

记录只保存非秘密连接标识、路径、大小、文件版本与 SHA-256 等核对数据。密码、密钥口令、私钥路径和主机信任不写入记录。恢复必须使用当前已连接并经用户核对的服务器，继续执行 SFTP 主机密钥及 TLS 证书验证。记录与锁文件权限为 600，目录为 700；读取拒绝符号链接、非普通文件、超限或无效记录，同一任务使用文件锁排除并发恢复。

下载先核对远程大小与时间/强 ETag、本机已保留内容、远程对应前缀；HTTP 使用 If-Match，并拒绝忽略 Range 或错误的 Content-Range。没有强 ETag 的源还会在提交前流式核对完整内容，避免秒级时间戳遗漏同大小修改。目标文件的完整内容与本机元数据也必须与开始时一致。

上传核对本机完整内容和元数据、远程暂存前缀，完成后再核对暂存的完整 SHA-256 与大小，检查目标版本后重命名。失败、取消和保留状态均不报告成功。提交前先写入记录；重启后可核对已经提交的目标内容并清理本任务遗留数据。下载在日志落后于实际追加字节时，会分别核对已记录前缀与完整部分内容再继续。

文件准备、源哈希和传输共用有界队列槽，批量选择不会提前启动无上限的元数据请求；排队/准备期间的暂停、保留和取消也传递到任务。本机哈希以 256 KiB 分块在 worker 执行，网络读取使用 libcurl 缓冲，支持取消；无每帧落盘或后台持续恢复扫描。远程前缀和完整内容校验会增加读取流量与等待时间，界面显示核对阶段。

本机下载提交使用同一文件系统内的一次原子重命名；不允许覆盖时使用排他重命名，避免检查后新出现的目标被覆盖。覆盖普通文件保留其 POSIX 权限。完整 ACL、扩展属性和时间戳保留尚未实现。普通 FTP/SFTP 等协议没有通用服务器锁或条件重命名，最终核对到提交之间仍可能发生并发写入；不承诺服务器侧事务隔离或断电持久性。未返回可核对大小与版本的服务器会拒绝安全续传。

## 验证范围

真实隔离服务器覆盖六种协议的下载保留/新实例恢复、FTP/SFTP/两种 FTPS 上传恢复、HTTP/HTTPS PUT 明确重传、错误 Range、同大小源改动、目标改动、取消清理、丢弃后旧实例拒绝运行，以及检查点落后时的恢复。额外覆盖准备前暂停/保留后恢复，并核对没有提前写入最终文件；本机提交回归覆盖拒绝覆盖、权限保留和连续 100 次替换。隔离服务器通过不等于所有真实服务兼容。

实际 macOS 窗口已完成 SFTP 下载保留、退出与重启恢复，最终 SHA-256 与源文件相同；离线丢弃和暂停后取消均核对无本任务检查点或部分文件残留。活动和恢复操作按钮可独立访问。UI 与短时空闲性能的证据范围见 [UI 与性能验收](performance.md)。
