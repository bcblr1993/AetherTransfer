# 文本编辑开发候选

文件行右键“编辑文本…”或 ⌘E 打开独立原生窗口；快捷键使用当前有焦点的窗格。支持本地、已连接 FTP/SFTP/WebDAV 服务器与 S3 对象的 UTF-8 文本，使用 AppKit NSTextView、系统查找栏、撤销与中文输入；关闭自动智能引号、破折号替换，避免改写代码。保留 UTF-8 BOM，未改动的 CRLF 按原字节保留。二进制、符号链接、目录、S3 前缀和超过 5 MiB 的内容拒绝进入编辑器；远程下载也在流式写入阶段执行大小限制，不能依赖服务器声明的大小。

初始读取及文本快照全部完成后才启用编辑和保存。取消或失败后保持只读、禁止保存，提供“重新读取”；取消发生在会话创建后的快照阶段时，独立清理任务仍会关闭自身会话，避免取消标记中断目录清理。

保存由明确点击“保存/回传”或 ⌘S 触发。会话绑定打开时的连接和文件，切换标签或断开浏览器不会把保存改投到其他服务器。草稿在权限 700 的独立临时目录、权限 600 的文件中保存；回传使用独立稳定快照，防止外部编辑器继续修改正在上传的输入。保存前读取原文件并核对 SHA-256，能发现同大小、同时间的内容变化；变化时保留草稿并拒绝此次覆盖。提交后再次核对字节摘要，未确认服务器结果不能显示保存成功。本地保存通过同一文件系统的临时路径替换，保留原 POSIX 权限。

“外部编辑器…”由用户选择本机应用，通过 NSWorkspace 打开草稿，并明确启用保存后自动回传；内置文本区域暂时只读。监听文件与父目录，覆盖原地写入和原子替换，不进行空闲轮询。保存事件合并后串行回传；发生冲突或网络失败后暂停自动回传，保留当前草稿，允许手动重试、停止自动回传、导出草稿、在 Finder 中显示草稿或重新载入后合并。

S3 沿用上述窗口与草稿流程。读取以 HEAD 的大小／ETag 固定版本，条件下载核对 SHA-256 并再次查询版本；保存前要求内容摘要与版本均未变化。上传额外传入打开或上次成功保存的版本，拒绝自动采用后来修改的对象版本，也不重建被其他客户端删除的对象；空 PUT 和 multipart 完成请求使用该 ETag 的 If-Match。保存后重新核对服务器内容与版本再更新编辑基线。失败保留草稿，abort 失败进入现有“保留的传输”清理列表；只有重新认证相同端点后才重试清理。

S3 的窗口标识保留原对象键 UTF-8 字节，避免把 Unicode 等价键归并到同一窗口；本地草稿单独映射安全文件名，超长名称使用带扩展名的短临时名称，服务器键和窗口显示名称仍保持原样。条件写入基于 ETag，不能识别更改后恢复相同 ETag 的所有历史；AWS/R2 实际账户及原生／外部编辑器 GUI 仍待验收，不以隔离协议通过替代。

S3 编辑代码 `a29ad86` 的两条 macOS 26 CI 均通过全部 32 项 HTTPS S3 测试，含六项编辑回归；取消打开用例在自身 work 树内观察未完成的真实部分文件后才取消，并核对会话清理和源对象不变。当前本机包完成清理构建、双语资源和签名验证，但 S3 编辑窗口与独立外部应用回传仍需实际 UI 验收。

窗口关闭与 App 退出检查正在进行的操作、未保存内容及外部编辑会话；不会静默丢弃。正常关闭会停止监听并清理自身临时目录；强制终止可能保留草稿，不能随构建清理脚本删除这些潜在用户内容。当前最多同时打开 12 个文本窗口。

限制：FTP/SFTP 及当前 WebDAV 保存没有服务器端原子条件写入/锁；其他客户端若在最后一次检查与提交之间更改文件，仍存在竞态，不能声称避免所有并发覆盖。断网后服务器最终状态可能不确定，暂存文件可能遗留，必须刷新核对。远程权限保留、UTF-16/其他编码、语法高亮、编辑器按扩展名配置、完整退出/重启草稿恢复、独立真实编辑器与服务矩阵仍待扩展。外部编辑器必须保持 UTF-8；大草稿或其他格式可在 Finder 中取出，不能无损转换后自动回传。

实现依据：[Apple NSTextView](https://developer.apple.com/documentation/appkit/nstextview)、[NSWorkspace 打开文件](https://developer.apple.com/documentation/appkit/nsworkspace/open(_:withapplicationat:configuration:completionhandler:))、[Dispatch 文件系统事件](https://developer.apple.com/documentation/dispatch/dispatchsource)、[Transmit 外部编辑工作流](https://help.panic.com/transmit/transmit-editors/)。

当前验收：23 项实际单元测试、29 项真实隔离协议测试与 arm64 release 构建通过。原生窗口读取 1,122,000 字节 SFTP 文本时取消，核对只读、保存禁用，粘贴与 ⌘S 未改动源文件；“重新读取”恢复完整初始文本。取消和关闭后均无新增临时会话，源 SHA-256 不变。该窗口回归覆盖网络读取阶段取消，不声称精确控制了快照阶段的微小时序。此前名为 `work` 的文件通过原生窗口保存，关闭后立即退出也确认目录移除。完整 macOS 26 UI、独立编辑器及服务矩阵继续保持开放；HTTPS fixture 当前边界见 `webdav.md`。
