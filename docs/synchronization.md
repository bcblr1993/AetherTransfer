# 目录同步

当前开发实现支持本地/本地、本地/远程与远程/远程目录组合。FTP、SFTP、显式/隐式 FTPS、WebDAV 与 S3 共用同步预览和队列；可从已连接的标签页选择目录。工具栏或 `⇧⌘S` 打开原生同步窗口。S3 镜像删除目前不可执行，详见下文。

## 预览与选择

- 单向向左/向右：复制缺少的文件，并按所选比较规则列出同名覆盖。
- 双向：复制两侧独有项目；同名差异需要逐项指定方向，没有持久历史来推断哪一侧应该胜出。
- 镜像：仅在单向模式列出目标多余项目，删除默认不选中。选择目录删除时必须包含所有实际子项；排除、隐藏或未选子项不会随父目录被删除。
- 修改日期比较同时检查大小，允许小于 60 秒的日期差；文件大小比较只比较字节数；内容比较计算 SHA-256。前两者不能证明内容一致。
- 可包含隐藏项目，按相对路径或任一级文件名排除项目；匹配为字面值，不支持通配符。远程日期可手动增加分钟偏移。
- 修改设置或目录会清除旧预览。用户确认覆盖/删除数量后，所选操作进入共享有界队列。失败或取消后需要重新预览。

符号链接和文件/目录类型冲突会阻止该项操作，不会跟随链接；同一实际目录或相互包含的目录拒绝同步。每侧最多扫描 100,000 项、128 层。

## 执行与磁盘占用

预览不改变两侧目录。执行前重新扫描并核对预览快照，逐项再次检查源、目标和父目录；已变更的计划拒绝继续。先建目录、再复制文件、最后从深到浅删除。

复制使用 64 KiB 有界缓冲、约 10 Hz 进度和单个文件暂存；取消会停止 worker 并清理本次暂存。远程内容比较逐个下载到权限 0700 的临时目录，单个文件比较完成后立即清理。创建暂存前检查可用磁盘空间，不缓存整个目录副本。本地覆盖先完成暂存再替换；本地删除移到系统废纸篓，远程删除没有产品内恢复功能，必须明确选中并确认。

这不是目录级事务：出现错误时停止，已完成操作会保留。FTP LIST 的分钟精度与时区可能掩盖同分钟同大小的变化；内容比较增加网络与磁盘读取成本。远程检查和 rename 之间仍存在外部并发修改窗口，不能宣称服务器级原子一致性。远程写入后的时间戳恢复、自动时差探测、通配规则、最近修改过滤、跟随链接、日志导出和持久双向同步历史仍待实现。

## S3 同步

S3 使用同一窗口的单向、双向、内容比较、逐项方向、排除与确认操作。桶根前缀为空；其他前缀保留原始 UTF-8 字节与分隔符，不经过 POSIX 路径归一化。同一桶的相同或包含前缀拒绝同步，签名区域不同不能绕过重叠检查。

快照保存文件和实际空目录标记的 ETag、大小及 HEAD 修改日期。即使只按大小比较，执行前也重新核对版本；上传固定原 ETag，缺失目标使用条件创建，下载固定源版本并校验内容。内容比较流式计算 SHA-256，不为 S3 比较生成磁盘副本。上传不会恢复本地修改日期，长期重复同步建议使用内容比较。ETag 不是 S3 VersionId；相同 ETag/大小/时间的 ABA 或外部并发创建前缀不能据此保证目录事务。

扫描最多 100,000 项、128 层，并将估算元数据限制在 32 MiB。名称验证在排除规则之前执行；拒绝点分量、空分量、大小写/Unicode 映射碰撞和含内容的目录标记。执行前验证全部目标键，包括目录末尾分隔符，并核对目标实际兄弟名称，避免排除项掩盖碰撞；超长键不会在创建部分目录后才失败。取消清理活动暂存与自身 multipart，已提交对象保留；abort 失败登记现有非秘密清理记录。

S3 镜像多余项目在预览中标为不可执行，不能勾选，也不能通过手工构造计划绕过执行门禁。AWS 已提供 [If-Match 条件删除](https://docs.aws.amazon.com/AmazonS3/latest/API/API_DeleteObject.html)，但当前固定版本测试服务的删除处理没有等价保护，见 [MinIO 删除处理源码](https://github.com/minio/minio/blob/7aac2a2c5b7c882e68c1ce017d8256be2feea27f/cmd/object-handlers.go#L2373) 和 [对应问题](https://github.com/minio/minio/issues/21677)。在兼容性与真实服务验收完成前，不降级为无条件删除。其他协议的明确镜像删除仍走原有路径。

S3/本地、S3/S3 的真实 HTTPS 回归与应用窗口验收分别记录；FTP/SFTP/WebDAV 与 S3 的交叉服务组合、AWS/R2 账户、完整中英文浅深色同步窗口仍须独立验收。

## 验证

`./scripts/test_core.sh` 包含本地真实字节同步、同名方向确认、同大小同时间的内容变化拒绝、父目录依赖、排除子项保护、重叠目录/链接拒绝，以及预暂停和写入途中取消的清理检查。`./scripts/test_protocols.sh` 包含四种协议的单向往返和明确镜像删除、FTP/SFTP 双远程双向同步及过期目标拒绝。

2026-10-09：清理后通过 72 项实际核心测试、37 项既有真实协议及 39 项 HTTPS S3 测试。新增 5 项核心和 7 项 S3 同步用例，验证嵌套/空/隐藏目录往返与内容无差异、S3/S3 双向方向确认、同大小源/目标 ETag 变化、全部键长度的首次写入前拒绝、排除名称碰撞、multipart 条件完成的并发拒绝及上传中取消的 abort/暂存清理。S3 镜像阻止执行并保留多余对象；真实服务不支持的 Unicode/点路径映射继续以核心防护与未来 AWS/R2 验收区分。当前同步窗口与动画仍待 GUI 验收。
