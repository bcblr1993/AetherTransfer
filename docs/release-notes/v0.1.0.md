AetherTransfer 首个正式版：为 Apple 芯片 Mac 打造的原生 SFTP / FTPS / FTP 文件传输工作台。
The first release of AetherTransfer, a native SFTP / FTPS / FTP workspace for Apple silicon Macs.

## 主要功能 / Highlights
- 本地与远程双栏、多标签工作区、快速查看、Finder 拖放 / Dual panes, tabs, Quick Look and Finder drag-and-drop
- 有界传输队列：暂停、取消、重试、限速、断点续传 / Bounded queue with pause, cancel, retry, throttling and resume
- 目录同步先预览再执行，默认不删除远程文件 / Previewed folder sync that never deletes remote extras by default
- 内置文本编辑回传、批量重命名、POSIX 权限编辑 / Built-in editor with save-back, batch rename and POSIX permissions
- SFTP 主机指纹核对、FTPS 证书验证、Keychain 凭据 / Host fingerprint checks, TLS validation and Keychain credentials
- 中英双语、浅深色外观、应用内安全更新 / English and Chinese, light and dark, verified in-app updates

## 系统要求 / Requirements
Apple 芯片 · macOS 26.0+ / Apple silicon · macOS 26.0+

## 已知限制 / Known limits
WebDAV、S3 / R2 尚未包含。/ WebDAV and S3 / R2 are not included yet.

SHA-256 见 `SHA256SUMS.txt`。/ See `SHA256SUMS.txt` for checksums.
