# 界面与双语规范

AetherTransfer 的界面目标是原生、清晰、精致、紧凑。中文和英文共用一套布局与交互，分别校对措辞与宽度；不按语言重建窗口、连接或编辑会话。实现入口为 `InterfaceStyle.swift` 中的共享组件、`AppPresentation` 与 Core 的 `L10n`。设计规范和代码统一是交付的一部分，实际窗口的视觉、输入和动效通过才算界面验收完成。

列表和新增列视图共用 `FileNameCell`，统一字体、28 pt 行高、18 pt 图标占位、名称中间截断与系统前景色；列视图的目录箭头留固定空间。列标题和空状态复用 caption／secondary 层级，260 pt 列宽来自共享常量，不叠加玻璃或为目录展开增加独立动画。三种浏览模式使用同一分段控件、文件菜单和选择入口。语言只更新可见原生单元格、列标题与辅助功能标签，保留目录和选择。

文件命令直接观察当前 Workspace，使菜单和工具栏的启用状态随选择、认证与加载更新，切换标签后不保留上一标签的动作目标。筛选与列历史准备在 worker 执行，取消传到准备任务；完整本地元数据用于三种模式的隐藏文件筛选，不增加目录 IO。缓存限制与原始 S3 路径规则见 `file-browser.md`。列视图仍须四组合实际检查，源码统一不代表视觉验收完成。

## 共享组件与状态

| 组件 | 使用范围与约束 |
| --- | --- |
| `SheetHeader` | 连接、指纹、同步、恢复、权限和重命名：36 pt 图标占位、统一标题和可换行说明；图标不重复朗读 |
| `SheetActions` | 上述弹窗共用：20 pt 外边距、12 pt 控件间距、至少 32 pt 内容高度；正文滚动时操作区仍可见 |
| `SheetFeedback` | 连接、恢复和重命名：提示／错误／进度紧邻操作区，最多 112 pt；短消息自然换行，长消息进入可滚动区域，不挤出按钮、不截断原错误 |
| `FormFieldRow` | 连接信息：150 pt 标签列、12 pt 间隔、至少 250 pt 原生输入区；英文标签可换行，字段保留自身辅助功能名称 |
| `SupportingText` | 中文／英文长说明均用 caption／secondary，可垂直换行，不用透明度降低对比度 |
| `InterfaceMessage` | 连接、权限、恢复、同步、编辑与预览：错误／警告同时提供图标、文字、语义色；错误文字可选择复制 |
| `InterfaceStatusBar` | 主窗口、文本编辑和预览：至少 36 pt 高、12 pt 横向边距、caption／secondary；长状态提供完整提示 |

连接、同步与指纹窗口采用相同的头部／正文／操作区分隔。恢复列表每个条目的继续操作使用普通原生按钮，避免多个条目同时以主色竞争；连接、应用权限、执行同步和编辑保存保留一个主要动作。文件信息面板的次要操作沿用系统按钮，正文不单独叠加玻璃。

欢迎页的图标使用系统 accent，协议标签在空间不足时改为两行；不能用水平溢出扩大窄窗格。编辑／恢复／预览中的长文件名中间截断，并提供完整名称提示。用户路径、名称和编辑内容保持原字节与原含义。

连接表单分为连接信息、认证与目录、连接设置。未填必填内容时，在固定操作区上方说明下一步，使用辅助文字而非首次打开就报错；失败信息和准备进度进入同一位置。端口保留文字草稿，允许删除／输入过程中暂时无效，只有 1–65535 的有效端口才可提交；使用 SSH 配置端口时按配置验证。修改相关草稿清除旧操作错误，不清空其他字段。错误过长时可滚动查看完整文字，按钮始终独立于该区域。

批量重命名刚打开或规则未填完整时仍显示所选原名称，新名称暂显示破折号、状态为待填写规则，执行与排除暂禁用；不显示红色无效规则错误。固定反馈区明确提示查找文字、前后缀、基本名称或具体编号范围。已有排除选择保留，规则有效后继续使用后台预览。文件列表、列视图、同步和重命名预览的原生表格由共享配置统一 28 pt 行高、系统字体、连续背景和系统选择样式。

浏览器自动焦点仅作初次后备：只在主窗口为键盘窗口、没有附加或模态弹窗，且当前焦点为空／窗口自身或另一个浏览器时请求。SwiftUI 宿主内容也不作为可夺取焦点的空白区域，因为控件可能在宿主中管理键盘焦点。文本编辑器、路径框、搜索框及其他控件已有焦点时不夺取；显式点击或键盘导航到浏览器后消费初始请求。该保护用于列表、图标和列视图，不能据此认定截图中的输入故障已复现实测解决。

连接、同步、保留进度和主机指纹弹窗共用图标、标题、说明的头部结构。取消靠左、主要动作靠右，Enter 触发有效的主要动作，Escape 取消；不可中断的保存期间禁用取消。危险操作使用明确的覆盖／删除说明，不设默认自动删除。

SFTP 认证使用同一标签宽度和原生 Picker，密码／私钥文件／SSH agent 只显示对应字段；agent 说明可换行，隐藏密码、口令和保存秘密开关。切换保留服务器与文件草稿，清空认证秘密；表单继续使用滚动正文和固定操作区。当前 578 项中英文资源一致性由脚本检查，认证切换的焦点、键盘与四组合仍待当前候选实机检查。

可选 SSH 配置沿用相同表单行，单独选择使用配置端口或显示手动端口输入；用户名／私钥留空的含义在占位说明中明确。后台解析错误留在当前表单，保留草稿；连接准备提供系统进度与取消按钮。指纹弹窗用同一标签列显示解析后的主机、端口和用户，再显示可复制指纹，不增加自定义动画或玻璃正文。配置及手动端口切换、长英文说明、焦点顺序与实际指纹窗口保持 GUI 待验收。

权限弹窗沿用同一标题／分组／固定操作区，三组访问者的复选框与八进制输入联动；特殊权限在折叠区，长文件名中间截断并保留完整路径提示。递归选项默认关闭，扫描后显示文件、文件夹与跳过链接的数量；改变范围保留草稿，“应用到全部项目”明确作用范围。权限观察对象独立于 Workspace 列表更新；数量和共同权限在后台计算一次，进度限频。应用时控件禁用、停止入口保持可用，完成与部分失败使用文字及图标。当前候选仍待中英文浅深色、键盘与辅助功能实机验收，见 `file-permissions.md`。

## 中文与英文

批量重命名复用同一表单和 28 pt 原生可复用列表，规则正文可滚动，主要操作固定；新名称、冲突、排除及实际结果共用状态列。连续输入在 worker 合并计算，更新期间保留已有列表并禁用执行，不增加逐行动画。中文／英文切换保留规则与排除选择；大小写、名称循环及停止结果的表格宽度、键盘和四组合仍待实机验收，见 `batch-rename.md`。

设置提供“跟随系统 / 简体中文 / English”。语言资源放在 Core 的 `Resources/zh-Hans.lproj` 与 `Resources/en.lproj`，由 SwiftPM 构建并嵌入 `.app/Contents/Resources`。打包校验兼容扁平与 Contents 两种资源 Bundle 结构，拒绝缺失语言、布局混杂和插值损坏。语言选择使用显式资源 Bundle；仅设置 Locale 不会自动切换资源查找语言。

菜单、工具栏、表格标题、右键菜单、弹窗、辅助功能标签及应用产生的错误文案均从资源表读取。设置窗口的 AppKit 标题也随语言更新，避免英文内容仍配中文窗口标题。日期和文件大小按所选语言格式化。系统控件本身、操作系统／第三方库返回的错误、系统文件类型名称可能遵循 macOS 的语言。

文件名、路径、收藏名称、服务器地址、编辑内容保持原样。任务内部状态值保持稳定，只在显示时翻译，避免语言改变影响暂停、继续、关闭保护和 Dock 汇总。已生成的历史错误／任务描述保留产生时的语言；后续事件使用当前选择的语言。

同步目录的“本地”标记在显示时翻译，目录标识与选择保持稳定；已打开的预览窗口标题和编辑器辅助功能标签随语言更新，保留文件名、内容、插入位置与撤销记录。该更新路径已编译检查，现存窗口切换仍属于实际双语矩阵的验收范围。

S3 同步沿用现有左右目录选择、方向、比较、差异表格、覆盖确认和共享队列。桶根目录与 S3 时间/镜像限制提供中英文说明；不可执行的镜像项沿用表格禁用状态，不增加独立的窗口样式。同步项保存稳定的操作原因，说明在显示时翻译，不再固定为生成预览时的语言；语言改变保留目录、勾选标识与冲突方向。新增说明的英文换行与四组合视觉验收仍须在当前运行候选中检查。

中文采用直接、简短的动词，例如“连接”“上传”“保留进度”；英文按原生桌面应用习惯使用 Connect、Upload、Keep Progress。打开后续窗口的菜单项使用省略号。数量文案用 `Selected: 1` 等结构避免不正确的单复数；插值仅使用经过校验的 `%@`，用户文字作为参数传入。

两种语言的视觉风格一致：系统字体自动选择适合文字的字形，不用中文等宽排版或英文全大写替代正文；英文句子按含义书写并允许换行。日期、大小、辅助功能状态随当前语言更新。禁止为消除英文溢出缩小正文、截断关键说明、缩小点击区或改变操作顺序。

## 动画与性能

标签的原生玻璃切换为约 180 ms，文字与文件区域不继承该动画。关闭按钮保留固定位置，首次增加标签不改变已有标签宽度。连接表单持有独立草稿，不订阅文件列表和传输进度；正文采用滚动分组与固定操作区。系统“减少动态效果”关闭自定义过渡。

活动面板展开／收起不对高度使用自定义动画，避免每帧改变两侧原生文件表格的尺寸；约 180 ms 的旋转只作用于披露箭头，并提供“已展开／已收起”辅助功能状态。连接加号继续使用系统 sheet 过渡，不另外叠加整窗缩放、模糊或弹簧。该调整的帧率收益仍需实际交互测量，不能仅凭代码推断通过。

切换语言只更新可见的原生表格／图标单元格与表头，保留文件数据、选中项和连接。文件 IO、协议请求、筛选和排序在 worker 执行；进度沿用受限更新频率，不为装饰增加计时器。动画验收以实际操作与 scoped trace 为准，不用静态截图或 Core 基准代替帧率。

## 验收门禁

- 中／英文 × 浅／深色：主窗口、连接、设置、同步、恢复、文件信息、编辑与预览。
- 连接弹窗：鼠标与 Tab 输入、SecureField、协议变化、长英文说明、Enter／Escape、错误与保存状态。
- 标签与加号：首次与重复点击、连接标签和空标签切换、活动任务保护、不丢失草稿或选择。
- 空／加载／错误／禁用状态：不出现按钮遮挡、说明截断或不能操作的旧文件行。
- 辅助功能：图标有语义标签，键盘可达；减少动态效果、减少透明度、VoiceOver 单独验收。
- 资源键与插值一致、核心及真实协议测试、arm64 release 打包与签名验证。
