# 文件权限

开发候选提供所选文件／文件夹及可选递归范围的 Unix 权限编辑，入口为文件信息栏、文件菜单和三种浏览视图的共用右键菜单。本地、FTP、显式／隐式 FTPS 与 SFTP 可用；WebDAV 与 S3 不显示为可编辑能力。FTP 的 SITE CHMOD 与 LIST -a 仍取决于服务器实现与账号授权，失败不会降级或报告成功。

弹窗沿用共享标题、系统字体、20 pt 边距、可滚动正文与固定操作栏。所有者／用户组／其他用户的读取、写入、执行控件与 3／4 位八进制值联动；特殊权限放在折叠区。单个或相同权限的多选预填当前值，混合权限要求明确选择完整目标权限。语言切换保留目标与草稿，不翻译文件名。鼠标、Tab、Enter／Escape、英文宽度和浅深色实际矩阵仍须验收。

递归默认关闭，勾选“包括文件夹中的项目”重新扫描并保留权限草稿。显示文件／文件夹数量和跳过的符号链接数量，再由“应用到全部项目”明确触发。包含隐藏文件和空目录；文件与文件夹使用同一目标权限，不能分别指定两种权限。显式选择的符号链接拒绝，目录内部的链接跳过且不跟随；其他特殊文件使扫描失败。重合选择只扫描最上层目录，硬链接核对各路径但不把自己的权限变化误报为外部变化。

读取、扫描、完整范围预检和逐项写入离开主线程，不读取文件内容。默认限制一百万个扫描项目、32 MiB 估算元数据和 64 层目录；任一上限到达就拒绝该范围，不能用截断结果应用。容量估算不是进程内存指标；协议响应还有现有缓冲上限。文件／目录数量和共同权限在 worker 计算一次，UI 不随每次进度更新遍历全树。扫描和写入可取消，进度最多约每 150 ms 更新。

批次在第一项写入前重扫并核对所有目标及目录成员，随后逐项核对；从子项到父目录应用，避免先收紧目录权限后无法修改内部项目。每个目录应用前再次核对直接成员。写入后重新读取实际权限。停止不自动回滚已应用权限，完成数量只计入写后核对成功的项目；写入后的断网／取消／变化可能留下无法确认的结果，必须刷新检查。执行开始后范围变化会停止剩余工作，已经核对的修改保留；不宣称全目录事务。

本地快照核对设备、inode、类型、所有者、大小、纳秒修改时间和权限。通常通过 NOFOLLOW 描述符核对并 fchmod，写后核对路径仍指向同一对象；符号链接、FIFO 等非普通文件／目录拒绝。本机文件权限为 0000 时，当前所有者可经 fchmodat 的 AT_SYMLINK_NOFOLLOW 修复；该路径不跟随末级符号链接，但路径写入与对象身份检查不是一个原子操作，不能保证外部并发替换下的条件修改。

远程快照核对路径原始字节、文件类型、大小、LIST 修改日期和权限；SFTP 使用 libcurl chmod，FTP 使用 SITE CHMOD。这些协议没有跨读取／写入的条件 chmod，列表日期也可能只有分钟精度；不宣称 inode／版本锁或外部并发修改下的事务。已知符号链接拒绝，但远程服务器的并发替换仍属于协议限制。

运行中的权限应用阻止切换此连接、关闭标签或退出应用；先停止或等待核对结束。任务取消沿用现有请求取消路径。弹窗不跟随文件列表／传输进度订阅，关闭后的读取任务可取消。

所有者／组修改、ACL、时间戳与上传后自动权限规则仍是完整 Transmit 对齐目标的待办，不能将本轮通过解释为完整元数据能力。递归弹窗及当前候选的四组合实际验收仍是独立门禁。

实现依据：[Transmit 文件权限工作流](https://help.panic.com/transmit/transmit5/files/#setting-permissions)、[libcurl SFTP chmod 与引用规则](https://curl.se/libcurl/c/CURLOPT_QUOTE.html)、[libcurl 自定义 FTP 列表命令](https://curl.se/libcurl/c/CURLOPT_CUSTOMREQUEST.html)。
