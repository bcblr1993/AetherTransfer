# 快速查看与文件信息

在本地或远程文件表格选中普通文件后，空格或 `⌘Y` 打开系统 Quick Look；右键菜单和文件信息栏也提供入口。预览窗口只保留一个，切换文件会先取消并清理上一项。音频和视频不自动播放，具体格式支持由系统 Quick Look 决定。

本地文件直接交给系统查看，不复制内容，也没有远程预览的大小限制。准备时拒绝目录、符号链接和特殊文件；本地文件之后被外部程序改变时，显示遵循系统文件查看行为，不承诺冻结快照。

远程文件先下载到独立的 0700 临时目录，保留原文件名和扩展名。默认最多 128 MiB；超过限制先拒绝，不创建缓存。复用传输的流式 IO、取消、源版本与内容核对，完整验证后才交给 Quick Look。预览不会写入远程服务器，也不会在本地浏览目录创建最终下载文件。准备时可取消或重试，切换、关闭窗口和正常退出会等待读取取消并清理自己的文件及检查点。

预览缓存位于当前用户临时目录下的应用专用 `com.aethernative.AetherTransfer.previews-v1` 目录。每个副本有 UUID 目录与独立的 `.lease` 归属记录；记录不包含服务器或凭据。远程文件放在 `payload/` 中，不会与归属记录或检查点同名冲突。

从准备读取到窗口关闭，副本持有内核排他文件锁。应用启动时在 worker 回收归属、权限和类型符合预期且未被锁定的副本；另一实例仍在使用的预览保持不动。进程退出会释放文件描述符和相应锁，下一次启动可以识别遗留副本。[Apple open 文档](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/open.2.html)、[close 文档](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/close.2.html)。

回收通过目录描述符操作，不跟随根目录、归属记录或 payload 的符号链接；未知记录、硬链接记录、权限不符和被替换的路径拒绝删除。清理失败显示实际错误，尽量保留锁记录供下一次启动重试。每轮最多读取 4096 个根条目、清理 4096 个内容项，单副本最多 16 层，超过上限保留记录并报告。后台回收可取消，退出会等待它停止；正常关闭预览的清理独立于读取取消。没有完整归属记录的初始化残留与旧版临时副本不自动删除，也不会扫描通用临时目录或用户文件夹。系统清除临时目录属于系统生命周期管理；断电损坏的记录不能当作可验证归属。

`⌘I` 或工具栏打开原生信息侧栏，随当前文件表格的焦点和选择更新。单项显示类型、路径、来源、大小、修改时间和已有权限文本；多项显示数量及所选文件大小。使用当前目录列表的元数据，不会额外递归扫描目录。目录大小、缺失权限与未知属性显示 `—`。权限修改、所有者、ACL、扩展属性和递归目录大小仍待开发。

协议验证覆盖 FTP、显式/隐式 FTPS、SFTP、HTTP/HTTPS WebDAV 的快照内容、大小限制和实际传输取消。平台 UI 验收与正式发行门禁分别记录，不以协议通过替代窗口运行检查。

缓存回归覆盖活动锁、两个回收者、符号链接、硬链接记录、目录替换、清理失败后重试和取消后保留记录；六种真实协议均验证服务器文件名 `.lease` 不覆盖归属记录。本机 macOS 27.0.1 实际 SFTP 窗口分别在已显示完整 PNG 和仍在读取的 1,500,000 字节文本中强制终止自己的测试实例，确认副本在重启前仍存在、重启后被回收。未知测试文件每次哈希不变；回收后的新预览正常显示、Escape 关闭后缓存为零、正常退出成功。隔离服务、输入和测试文件已移除。此验证覆盖进程强制终止，不等同于断电或损坏文件系统验收。

本机 macOS 27 实际窗口覆盖 PNG、中文 UTF-8、空格/⌘Y、Escape/关闭按钮、取消/重新读取、读取中退出及文件信息选择联动；远程副本哈希一致，结束后临时目录为零且本地输入不变。系统 inspector API 在此嵌套布局中连最小文本内容也触发约束循环，信息栏采用固定 280 pt 的 SwiftUI 主内容侧栏，保留系统控件和材质；完整 macOS 26 UI 与侧栏拖动调宽仍待验证/实现。Quick Look 由 SwiftUI dismantle 显式关闭，关闭随窗口自动处理会重复 deactivate，实际关闭回归已修复此问题。
