# 文件浏览

开发候选支持列表和图标两种原生呈现。本地与远程窗格独立，每个标签保留自己的视图模式；新标签默认列表，退出后不恢复模式。列视图、可调图标大小、文件缩略图及完整浏览状态持久化尚未实现。

窗格标题旁的系统分段控件切换视图；Command-1 / Command-2 切换当前焦点窗格。文件 ID 维持同一选择，切换后恢复键盘焦点，Space 快速查看，Return 打开当前选择。图标支持 AppKit 键盘多选；双击打开实际点击的文件，空白双击不打开已有选择。排序菜单按名称、大小或修改时间升降序排列，筛选和隐藏文件设置沿用列表行为。

两种视图共享右键菜单：打开或下载、文本编辑、快速查看、文件信息、上传、重命名和删除。操作沿用既有工作流、冲突确认和安全传输，图标不单独实现网络请求。

图标采用 [NSCollectionView](https://developer.apple.com/documentation/appkit/nscollectionview) 和 [NSCollectionViewFlowLayout](https://developer.apple.com/documentation/appkit/nscollectionviewflowlayout)，复用 AppKit 单元格。后台筛选/排序完成后才替换数据版本，不将每个文件放入 SwiftUI 布局或玻璃动画。类型图标来自系统 UTType，不读取文件内容、不下载远程缩略图；类型图片使用 countLimit 为 128 的 NSCache，属于缓存回收策略，不能视作整个进程内存上限。名称显示最多两行，完整名称保留于提示与辅助功能标签。

玻璃仍集中于系统工具栏、标签和操作控件，文件区域使用清晰的原生内容呈现。依据 [Apple Liquid Glass adoption](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)。

- 键盘多选、大小升降序、无匹配空状态、隐藏文件、文件夹双击和自建文件重命名通过。列表共享右键菜单打开文件信息通过。

## 文件 URL 拖放

列表和图标的滚动区共用 AppKit 文件 URL 接收入口。本地源只提供复制，远程栏接收去重的文件 URL；未连接、连接中、远程载入中或文件区禁用时拒绝。空目录提示不拦截输入，接受时用系统强调色描边。上传在后台读取本地元数据前固定目标连接、路径和同名文件快照，再进入已有队列、递归与冲突工作流；实际目标始终是当前目录，尚无悬停进入文件夹或投放到具体文件夹的行为。

2026-10-08 增补验收：

- 诊断构建中，列表单文件及图标多选文件/目录拖入远程栏产生真实 SFTP 任务。原生拖动后继续一次目标点击，才完成自动化输入中的投放；接收回调分别得到 1 / 2 个 URL。三个叶文件 SHA-256 与本地源一致，递归任务处理 2 / 2 项，源文件保留。
- 移除全部鼠标/拖放诊断日志并重建后，实际窗口核对指纹、上传到空目录、保留两份与冲突取消通过。图标多选中文文件和目录通过工具栏完成递归上传，目标哈希一致。取消不增加任务，最终四项完成。
- 最终构建的坐标输入控制器返回 `noWindowsAvailable`；应用绑定刷新、控制运行环境重置、窗口置前及系统尺寸还原均未恢复拖动。语义辅助功能操作和真实传输可用，但不能代替原生投放验证。因此空目录拖放和最终候选拖放保持待验收。
