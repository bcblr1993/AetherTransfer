AetherTransfer 0.3.0：Transmit 5 深度对齐——FTP Active/ASCII 模式与原始命令控制台、S3 预设 / `ListBuckets` / AWS STS `AssumeRole`、多客户端书签导入、安全 Zip 解压、编辑器查找替换与多编码、高级同步干跑与 CSV、Files 偏好与 View Options。
AetherTransfer 0.3.0 delivers deep Transmit 5 parity across FTP Active/ASCII & raw console, S3 presets / `ListBuckets` / AWS STS `AssumeRole` + MFA, bookmark importers, safe zip extraction, editor Find & Replace + multi-encoding, Sync dry-run & CSV export, Files preferences, and View Options.

## 主要更新 / Highlights
- **FTP 与原始命令控制台 / FTP Modes & Raw Console**：支持 FTP Active/Passive 切换、全局与单连接 `Automatic / ASCII / Binary` 传输模式，以及内置 Raw FTP/SFTP 命令控制台（控制字符注入拦截与日志脱敏）。
- **S3 预设、桶发现与 STS `AssumeRole` / S3 Presets, Discovery & STS**：新增 AWS S3、IAM Role/STS、Cloudflare R2、MinIO、DreamObjects、Wasabi 与 DigitalOcean Spaces 预设；支持 `ListBuckets` 与 AWS STS `AssumeRole` + MFA 临时会话凭据（`X-Amz-Security-Token`）。
- **书签导入与安全解压 / Importers & Safe Zip Extract**：支持导入 FileZilla XML、Cyberduck `.duck`、Transmit Favorites/`.inetloc`、`~/.ssh/config` 与 `~/.aws/config`；本地 Zip 解压支持预扫描拦截 Zip-Slip 与符号链接逃逸。
- **编辑器、同步、偏好与菜单 / Editor, Sync, Preferences & Menus**：内置编辑器新增查找与替换（`⌘F`）及 UTF-8 / UTF-16 / ISO-8859-1 / GB18030 编码；同步新增时差补偿与自动检测、修改时间窗口、跟随符号链接、Simulate 干跑与 CSV 导出；新增 Files & Editors 偏好设置（按扩展名指定自定义编辑器）、View Options（`⌘J`）、活跃传输关闭/断连守护与完整 macOS 菜单快捷键。

## 系统要求与范围 / Requirements & Scope
Apple 芯片 · macOS 26.0+ / Apple silicon · macOS 26.0+
需第三方 OAuth 应用凭据的消费级云盘（Box、Dropbox、Google Drive、OneDrive）暂未包含。/ Consumer OAuth cloud drives (Box, Dropbox, Google Drive, OneDrive) require third-party OAuth app credentials and are not included.

SHA-256 见 `SHA256SUMS.txt`。/ See `SHA256SUMS.txt` for checksums.
