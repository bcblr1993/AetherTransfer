# 快速查看与文件信息

在本地或远程文件表格选中普通文件后，空格或 `⌘Y` 打开系统 Quick Look；右键菜单和文件信息栏也提供入口。预览窗口只保留一个，切换文件会先取消并清理上一项。音频和视频不自动播放，具体格式支持由系统 Quick Look 决定。

本地文件直接交给系统查看，不复制内容，也没有远程预览的大小限制。准备时拒绝目录、符号链接和特殊文件；本地文件之后被外部程序改变时，显示遵循系统文件查看行为，不承诺冻结快照。

远程文件先下载到独立的 0700 临时目录，保留原文件名和扩展名。默认最多 128 MiB；超过限制先拒绝，不创建缓存。复用传输的流式 IO、取消、源版本与内容核对，完整验证后才交给 Quick Look。预览不会写入远程服务器，也不会在本地浏览目录创建最终下载文件。准备时可取消或重试，切换、关闭窗口和正常退出会等待读取取消并清理自己的文件及检查点。

临时目录清理失败会显示真实错误。强制终止或系统崩溃后的缓存回收仍待实现；当前不扫描或删除其他会话的临时目录。

`⌘I` 或工具栏打开原生信息侧栏，随当前文件表格的焦点和选择更新。单项显示类型、路径、来源、大小、修改时间和已有权限文本；多项显示数量及所选文件大小。使用当前目录列表的元数据，不会额外递归扫描目录。目录大小、缺失权限与未知属性显示 `—`。权限修改、所有者、ACL、扩展属性和递归目录大小仍待开发。

协议验证覆盖 FTP、显式/隐式 FTPS、SFTP、HTTP/HTTPS WebDAV 的快照内容、大小限制和实际传输取消。平台 UI 验收与正式发行门禁分别记录，不以协议通过替代窗口运行检查。

本机 macOS 27 实際窗口覆盖 PNG、中文 UTF-8、空格/⌘Y、Escape/关闭按钮、取消/重新读取、读取中退出及文件信息选择联动；远程副本哈希一致，结束后临时目录为零且本地输入不变。系统 inspector API 在此嵌套布局中连最小文本内容也触发约束循环，信息栏采用固定 280 pt 的 SwiftUI 主内容侧栏，保留系统控件和材质；完整 macOS 26 UI 与侧栏拖动调宽仍待验证/实现。Quick Look 由 SwiftUI dismantle 显式关闭，关闭随窗口自动处理会重复 deactivate，实际关闭回归已修复此问题。
