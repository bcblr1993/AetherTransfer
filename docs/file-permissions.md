# 文件权限

开发候选提供所选文件／文件夹的 Unix 权限编辑，入口为文件信息栏、文件菜单和三种浏览视图的共用右键菜单。本地、FTP、显式／隐式 FTPS 与 SFTP 可用；WebDAV 与 S3 不显示为可编辑能力。FTP 的 SITE CHMOD 仍取决于服务器实现与账号授权，失败不会降级或报告成功。

弹窗沿用共享标题、系统字体、20 pt 边距、可滚动正文与固定操作栏。所有者／用户组／其他用户的读取、写入、执行控件与 3／4 位八进制值联动；特殊权限放在折叠区。单个或相同权限的多选预填当前值，混合权限要求明确选择完整目标权限。语言切换保留目标与草稿，不翻译文件名。鼠标、Tab、Enter／Escape、英文宽度和浅深色实际矩阵仍须验收。

读取、完整选择预检和逐项写入离开主线程，不读取文件内容。批次在第一项写入前核对所有目标，再逐项核对；写入后重新读取实际权限。进度最多约每 150 ms 更新。停止不自动回滚已应用权限，完成数量只计入写后核对成功的项目；写入后的断网／取消／变化可能留下无法确认的结果，必须刷新检查。

本地快照核对设备、inode、类型、所有者、大小、纳秒修改时间和权限。通常通过 NOFOLLOW 描述符核对并 fchmod，写后核对路径仍指向同一对象；符号链接、FIFO 等非普通文件／目录拒绝。本机文件权限为 0000 时，当前所有者可经 fchmodat 的 AT_SYMLINK_NOFOLLOW 修复；该路径不跟随末级符号链接，但路径写入与对象身份检查不是一个原子操作，不能保证外部并发替换下的条件修改。

远程快照核对路径原始字节、文件类型、大小、LIST 修改日期和权限；SFTP 使用 libcurl chmod，FTP 使用 SITE CHMOD。这些协议没有跨读取／写入的条件 chmod，列表日期也可能只有分钟精度；不宣称 inode／版本锁或外部并发修改下的事务。已知符号链接拒绝，但远程服务器的并发替换仍属于协议限制。

运行中的权限应用阻止切换此连接、关闭标签或退出应用；先停止或等待核对结束。任务取消沿用现有请求取消路径。弹窗不跟随文件列表／传输进度订阅，关闭后的读取任务可取消。

当前范围只修改明确选中的项目。递归应用、所有者／组修改、ACL、时间戳与上传后自动权限规则仍是完整 Transmit 对齐目标的待办，不能将本轮通过解释为完整元数据能力。

实现依据：[Transmit 文件权限工作流](https://help.panic.com/transmit/transmit5/files/#setting-permissions)、[libcurl SFTP chmod 与引用规则](https://curl.se/libcurl/c/CURLOPT_QUOTE.html)。
