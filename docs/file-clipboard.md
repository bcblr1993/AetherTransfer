# 文件剪贴板与粘贴计划

此阶段包含原生“复制路径”入口，以及供后续复制／移动使用的只读预览 API。文件剪贴板、粘贴窗口和复制／移动执行器尚未接入，不作为完整 Transmit 文件操作交付。

## 复制路径

列表、图标与列视图使用相同的中英文“复制路径”菜单。文件浏览器持有键盘焦点时，系统复制命令（⌘C）读取原生控件的当前选择，按可见顺序写入文本剪贴板，每行一个路径。列视图使用所在列的快照，不借用另一列的当前目录。

本地和文件服务器使用文件路径，S3 使用原始对象键／前缀；不生成连接 URL，不写入服务器资料或凭据。只声明文本类型，不将路径标记为可粘贴的 Finder 文件。空选择、禁用或正在刷新时不改动剪贴板。路径输入框与编辑器保留系统 responder chain 的文本复制行为。

原生菜单校验和独立命名剪贴板的真实读写可由应用测试验证；三个视图的鼠标／⌘C、文本输入焦点及四组合窗口仍需当前运行包验收。

## 只读预览

`FilePaste.preview` 接受一个或多个 `FilePasteInput`、目标 `SyncRoot`、冲突策略、排除集合和移动意图。可从本地、FTP、SFTP、显式／隐式 FTPS、WebDAV／HTTPS 与 S3 目录读取元数据。移动意图仅保存在计划中，不会移动或删除源。

- 拒绝／覆盖合并／跳过／保留两份共用目标名称检查。不同源目录的同名项目不得预订同一目标；保留两份分别分配可用名称，排除采用原始选择 ID。
- 计数包含所选根项目、隐藏文件、空文件和空目录；覆盖计数仅包含匹配的普通文件。目录合并保留目标额外项目，文件／目录类型冲突阻止执行准备。
- 同目录保留两份允许预览；写回自身、文件夹放入自身或后代、互相包含的源选择会阻止或拒绝计划。名称映射保守地拒绝大小写和 Unicode 别名冲突。
- 本地扫描在 worker 通过目录描述符、`openat` 与不跟随链接的版本检查读取，祖先检测通过描述符逐级向上，兼容 macOS `/var` 等系统路径别名。所选子树含符号链接或特殊文件会拒绝，未选中的链接不参与扫描。
- 远程列表显式包含隐藏项目；每个目录一次 LIST，每个普通文件读取版本。S3 使用原始前缀与 ETag，验证空目录标记和 1,024 字节对象键上限，不做 POSIX 路径归一化。
- 每次预览最多 1,000 个选择、100,000 个扫描项目、32 MiB 的估算元数据及 64 层子目录。根列表也计入元数据预算；这不是进程峰值内存保证。取消会停止准备，不写文件。

`FilePaste.validate` 重新核对原始根解析、根身份、目标根名称集合，以及选中源／对应目标的完整树。预览后原子替换、增加隐藏项目、类型变化、版本变化或前缀消失会拒绝。本地普通文件保存设备／inode、权限／所有者、大小及纳秒 mtime／ctime；远程文件沿用协议可提供的大小／mtime／ETag，目录沿用可用权限或 S3 标记。

这些元数据是过期检测条件，不是内容散列或事务锁。FTP 等协议同大小、同时间戳的内容变化以及远程目录身份替换未必可检测；目标在验证之后仍可能变化。此 API 不允许执行器据此直接报告传输成功。

## 后续执行与验收

仍需文件剪贴板生命周期、粘贴／移动的统一双语窗口、逐项排除与覆盖确认、队列／取消／部分结果，以及复制后的内容校验。覆盖时必须在实际提交前重查目标；移动须在目标校验成功后才处理源，并明确协议无法原子保护的范围。跨服务器传输需要本地中转及有界临时文件清理。S3 的条件写入／条件删除能力与真实 AWS／R2 服务要独立验收。

本阶段测试使用实际临时目录、六种隔离文件服务器和隔离 HTTPS S3，核对预览未改动两侧数据与过期计划拒绝。S3 真实测试使用含中文、空格及 `+#%` 的编码前缀，并只读验证 1,024 字节的目标键映射与超长保留两份名称拒绝；不向服务写入该最大目标键。隔离服务在测试准备阶段对空／点路径分段及过长单一名称返回 HTTP 400，原始特殊前缀仍需 AWS／R2 实际服务验收。已有原始前缀映射单元测试不代替此验收。它们也不代替执行器或原生窗口检查。
